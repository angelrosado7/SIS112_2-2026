Unidad: Enteros

Los enteros representa números sin parte decimal (positivos, negativos y el cero). Son la base para contadores, iteraciones y operaciones matemáticas fundamentales.

Python 3 - Ejemplo Enteros 
# Operaciones básicas con enteros
a = 10
b = 5

suma = a + b
multiplicacion = a * b
division_entera = a // b  # Retorna la parte entera

print(f"Suma: {suma}")
print(f"Multiplicación: {multiplicacion}")
print(f"División Entera: {division_entera}")

Unidad: Cadenas (Strings)

Secuencias de caracteres encerradas entre comillas. Se utilizan para manipular texto, generar mensajes y procesar entrada de datos.

Python 3 - Ejemplo Cadenas 
# Manipulación de cadenas de texto
materia = "Programación I - UCB"

# Métodos comunes
mayusculas = materia.upper()
longitud = len(materia)
primer_caracter = materia[0]

print(f"Texto en mayúsculas: {mayusculas}")
print(f"Longitud de la cadena: {longitud}")
print(f"Primer carácter: {primer_caracter}")

Unidad: Listas

Estructuras de datos mutables y ordenadas que permiten almacenar colecciones de elementos heterogéneos bajo una misma variable.

Python 3 - Ejemplo Listas 
# Creación y manipulación de listas
carreras = ["Sistemas", "Telecomunicaciones", "Industrial"]

# Agregar elemento al final
carreras.append("Mecatrónica")

print(f"Lista completa: {carreras}")
print(f"Primera carrera: {carreras[0]}")

Unidad: Diccionarios (Matrices)

Colecciones desordenadas de pares clave: valor. Son ideales para mapear estructuras complejas, representar datos tabulares y modelar matrices dispersas.

Python 3 - Ejemplo Diccionarios y Matrices 
# Diccionario básico
estudiante = {
    "nombre": "Juan Pérez",
    "carrera": "Sistemas",
    "nota": 95
}

print(f"Nombre: {estudiante['nombre']}")
print(f"Nota final: {estudiante['nota']}")

# Representación de una Matriz usando Diccionario (matriz dispersa)
matriz = {
    (0, 0): 1, (0, 1): 5,
    (1, 0): 3, (1, 1): 8
}

print("\nRepresentación de matriz 2x2 usando diccionario:")
print(f"Valor en fila 0, col 1: {matriz[(0, 1)]}")
